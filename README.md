Веб-застосунок для тестування учнів під час підготовки до НМТ з математики. 
Платформа поєднує перевірку знань з можливістю повторення теоретичного матеріалу, що допомагає учням систематизувати знання та відстежувати власний прогрес.

Реєстрація та авторизація користувачів
Проходження тестів з основних тем НМТ з математики
Автоматична перевірка відповідей
Повторення та перегляд навчальних матеріалів за темами
Зручний інтерфейс для навчання та самоперевірки
